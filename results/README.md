# Results of the run reported in the paper

Aggregate tables written by `run_all.R` (no participant-level data). File names follow the table numbers in the paper and its Supplementary Appendix.

| File | Contents |
|---|---|
| `Table1_baseline.csv` | Table 1 |
| `Table2_model_performance.csv` | Table 2 |
| `TableS1_data_dictionary.csv` … `TableS10_SHAP_summary.csv` | Supplementary Tables S1–S10 |
| `SHAP_exact_mean_absolute.csv` | Mean absolute exact Shapley values (Figure 3) |
| `key_numbers.csv` | Numbers quoted in the text |
| `per_repeat_measures.csv`, `per_repeat_classification.csv` | Performance of each model in each repeat |
| `tuned_hyperparameters_by_fold.csv`, `final_model_hyperparameters.csv` | Tuned hyperparameters |
| `auroc_summary_unrounded.csv`, `dca_fine_grid_final_model.csv` | Unrounded AUROC summary; net benefit on a 1% grid |
| `verification_report.md`, `verification_report.csv` | Every reported value compared with the code's output |
| `sessionInfo.txt` | R session information |
